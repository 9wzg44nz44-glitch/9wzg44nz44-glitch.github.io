Radiated fields: sleeve-balun stub vs SMA end

Different experiment (not this cage): Monstein–Wesley 2002 brass-rod polarizer — monstein.html.

Educational cartoon of expected transverse (TEM) vs longitudinal / scalar (SLW) patterns for Dan’s 23 cm HAM bench: TinySA Ultra 406 in square-wave / mixer region at 1296.000 MHz, Hively-style sleeve-balun stub (not the patent skirt), optional female-SMA leak, two RadioScreen mesh tents. Mainstream classical electrodynamics (CED) is TEM. SLW / extended electrodynamics is not settled physics. Numbers are the same toys as the older SNR pages, driven here by TinySA dBm instead of a 5 A slider.

Build language: close-fitting λ/4 sleeve (bazooka choke) soldered at the cold end, open at the stub tip — setup.html#sleeve. US 9,306,527 Fig. 2A’s fat annular skirt is historical patent geometry and can launch extra TEM; do not build that skirt for this 1296 MHz cage.

Not a measurement. Square-wave drive is full of harmonics and mixer spurs — not a clean sine. Sealed mesh is quoted 50–60 dB RadioScreen, not Hively’s copper-pipe 25,000 dB. Licensed milliwatts on 23 cm only. No magnetron.

Default sealed = 55 dB per tent, two tents so power is down 110 dB if you apply both. That is still a mesh screen, not 2885 copper skin depths. Near-field: lab r is often inside 2D²/λ for a small stub — Friis is a far-field estimate, labeled as such.

Assumptions stated in the equations section: 50 Ω, RBW B = 100 kHz (log the real RBW), thermal floor N0 = −174 dBm/Hz at 290 K, Hively NF = 3 dB unless LNA on (NF ≈ 5 dB, +20 dB gain on Psig only — still illustrative). TinySA input is 50 Ω when internal atten ≥ 10 dB.

Equations on this page (as coded)

f = 1.296×109 Hz, c = 299792458 m/s, μ0 = 4π×10−7, Z0 = 376.73031346177 Ω, RL = 50 Ω.

TinySA → current

P = 10^((P_tx,dBm − 30)/10)   W into 50 Ω
I_rms = sqrt(P / 50)
I_peak = I_rms * sqrt(2)

TEM received (Friis, far-field; honest near-field caveat)

G_tx ≈ 1.5  (short monopole, linear, not dBi marketing)
A_eff,TEM = 3λ² / (8π)     (same short-monopole estimate)
P_rx,TEM = P_tx * G_tx * A_eff,TEM / (4 π r²)   [far field]
P_rx,mesh = P_rx * 10^(−Att_dB / 10)   per tent; two tents when sealed
SNR_TEM,dB = P_rx,dBm − (−174 + 10 log10(B) + NF)
B = 100 kHz   NF = 3 dB (5 dB if LNA box checked)
Near-field flags when r < 2 D²/λ with D ≈ λ/4 stub, or r < λ/(2π).

Hively SLW (US 9,306,527 Eq. 15 — same JS as Hively-SNR-Simulator)

P_rad = I_peak² Z_0 / (4π)     (patent Eq. 15; isotropic SLW cartoon)
S(r) = P_rad / (4π r²)
A_eff = π (0.05)² = 7.854×10⁻³ m²   (10 cm palm coil, η = 0.50)
P_load = S A_eff η * 10^(−Att_dB/10) per tent
SNR_Hively,dB = P_load,dBm − (−174 + 10 log10(B) + NF)

Old HTML sliders used I ≈ 5 A (P_rad ≈ 749 W). This page uses TinySA milliwatts, so P_rad is tiny. The shape of S∝1/r² is the toy; do not treat 5 A as a TinySA number.

Nikolova–Zimmerman analytic A(r) (CEM-R-46 2007)

k_0 = 2π f / c
A_m(r) = μ_0 I_peak / (2π k_0 r)     Wb/m   (peak)
R = 264030 m/H
I_RMS = (R / √2) A_m
P_sig,NZ = I_RMS² * 50 * mesh_power

Zimmerman 2011 lab-anchored A_z(r)

A_z = 10⁻¹⁰ * (I_peak / 0.028) * (1.5 / r) * (1.3 / f_GHz)   Wb/m
       (anchor: 10⁻¹⁰ Wb/m at 1.5 m, 10 mW, I_ref = 28 mA)
I_rms,Z = 420000 * A_z
P_sig,Z = I_rms,Z² * 50 * mesh_power
