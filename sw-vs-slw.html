What this bench actually measures

The working apparatus is an SLW-class launcher/receiver:

  • balun monopole (1296 MHz build: close-fitting sleeve / bazooka; patent Fig. 2A skirt is historical) and/or bifilar pancake
  • TinySA / conventional RF chain
  • Faraday-cage and seawater-cell attenuation runs
  • PMT / optical side channel as a downstream effect sensor, not a first-principles C meter

Those antennas couple to the pair (C, EL). They can support SLW-class statements about gradient-driven channels, Faraday penetration vs TEM skin estimates, and seawater loss on a channel that still has EL. They cannot support âthe surviving tone is a pure SW.â Cage penetration and PMT response are not SW proof.

Why the same bench is not an SW detector

  1. No E-null at the receiver. Bifilar or balun monopole still responds to residual longitudinal E.
  2. No independent field inventory. SW needs three simultaneous channels: loop â B; short dipole / E-probe â EL; bifilar / second balun monopole â C + residual EL. SW is only when the first two die in a conductor and the third remains. This bench does not log that triad.
  3. No field-free potential sensor (Josephson/SQUID or Puthoff-class AâÎ¦ architecture) in the current RF chain. Naming an architecture is not evidence a test was run.
  4. No isolated information channel. Public EED work shows CW/swept tones through cages, not a modulated payload that exists only in C. Zimmerman plasma-tube work is a different ontology. Meyl kits are not used as evidence here.

What would have to be added for an SW claim

  1. Launch with the existing gradient-driven source.
  2. Receive on the three-channel set (loop / E-probe / bifilar).
  3. Insert conductivity (seawater cell, then steel plate/can).
  4. Require: loop and E-probe die; bifilar tone remains; TEM leakage paths closed.
  5. AM or slow FSK on the drive; recover the same spectrum on the surviving channel.

Repo stance: SLW-class hardware; SW requires E=B=0 isolation, a three-channel (B / EL / C) conductor test, and a modulated payload on the surviving C channel.
