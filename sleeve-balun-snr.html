Cable guidance (educational)

Conservative handbook-ish continuous RF current cautions — not a datasheet warranty:

  • Thin flexible SMA jumpers: ~0.1–0.5 A Irms caution
  • RG-405 semi-rigid: higher, educational caution ~1.5 A Irms
  • RG-450-class / heavier rigid SMA: educational caution ~3 A Irms; above that → thicker cable or external PA
  • TinySA Ultra generator: typically milliwatts; clean region ≲ +10 dBm; flag above ~+15 dBm

See physics-constants.json → cable_limits_educational.

Equations on this page (as coded — hub chains only)

f ∈ {1.296×109, 2.45×109, 4.3359×108} Hz · c = 299792458 · μ0 = 4π×10−7 · Z0 = 376.73031346177 · RL = 50.

TinySA → current

P = 10^((P_tx,dBm − 30)/10)   W into 50 Ω
I_rms = sqrt(P / 50)
I_peak = I_rms * sqrt(2)
# high-I mode: set I_peak directly; back-compute P = I_rms²·50

TEM received (Friis; honest near-field caveat)

G_tx ≈ 1.5
A_eff,TEM = 3λ² / (8π)
P_rx,TEM = P_tx * G_tx * A_eff,TEM / (4 π r²) * mP
mP = 10^(−2·Att_dB/10)   # two tents
SNR_TEM,dB = P_rx,dBm − (−174 + 10 log10(B) + NF)
Near-field flags when r < 2 D²/λ with D ≈ λ/4.

Hively SLW (US 9,306,527 Eq. 15 — same JS as fields.js)

P_rad = I_peak² Z_0 / (4π)
S_geom = P_rad / (4π r²)
S = S_geom * exp(−α_ohm L_eff)   # experiment-c-snr; SW → α=0
loss_dB = 4.343 * α_ohm * L_eff
A_eff = π (0.05)² · η = 0.50
P_load = S A_eff η * mP * 10^(lnaGain/10)
SNR_Hively,dB = P_load,dBm − (−174 + 10 log10(B) + NF)
