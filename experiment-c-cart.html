TinySA wiring reminder

PMT → C12597 → C9663 (50 Ω) → attenuator → TinySA Ultra SMA. Set TX AM to fmod ≥ 100 kHz. Never raw anode. Details: experiment-c.html#tinysa.

Suggested buy order

  1. Amp + attenuator + coax + confirm TinySA sees a test tone from a function gen (electronics dry-run, <$500).
  2. Quote Hamamatsu R8486 + C12597-01; order Newport 10BPF10-239 + mounts.
  3. Integrate optical mid-UV → TinySA with RF AM on the cage TX.
  4. Quote R8487 + 122 nm filter + purge; add Lyman-α channel.
  5. Only then: atomic-H source and/or 243 nm clock laser.
