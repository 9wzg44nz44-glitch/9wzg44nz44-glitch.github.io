FX-1 SNR — driven Faraday sphere, standard physics vs EED (v0.1 draft)

Predicts what the Tekbox E5, H10, H20 and H5 probes should read on a TinySA Ultra for the FX-1 home experiment. Setup: two ~11″ stainless bowls (R ≈ 0.14 m) driven at 433.59 MHz from TinySA #1 through a Zeenko ZK06-UM 21 dB amp (~+2 dBm, ~0.4 V peak on the shell). TinySA #2 sits inside, TinySA #3 outside. Each reading is shown two ways. Standard physics uses textbook formulas with labelled modelling assumptions. HYP uses the page's EED Er inside and the SleeveBalunSNR carry-over rules outside.

Wolfram Cloud twin: wolframcloud.com/obj/danbritton5/FX1SNR, Cloud twin pending sync (fx1-snr-v0.1). The page is live ahead of the Cloud object. FX1SNR.wl uses the same constants file and version and is ready to CloudPublish. Status is tracked in the hub sync ledger. openEMS reference: see openEMS reference (FDTD of the sphere + counterpoise, separate worker; reference data, not engine physics).

Not a measurement. EED/SLW is not settled physics. The HYP interior numbers assume the shell pins Φ = V0 cos Ωt at its surface, as the page says, and V0 comes from the page's 50 Ω conversion. Probe factors are Tekbox's published EMC-sniffer curves; Tekbox warns that sniffer probes distort the field. The TinySA noise floor uses the published 30 MHz spec, and applying it at 433 MHz and above is an ASSUMPTION.

Equations (as coded — identical in FX1SNR.wl)

Drive

P = 10^((P_dBm − 30)/10) W
V0 = sqrt(2·50·P)          # ASSUMPTION, as the page does: +2 dBm → 0.398 V; −19 dBm → 35.5 mV
I_pk = sqrt(2P/50)         # hub 50 Ω identity (SleeveBalunSNR)

Interior — standard FACT forms + ASSUMPTIONS

Ideal closed conductor: E = 0, B = 0 inside                                    # FACT
E_ref = V0/R  (surface field of a sphere at potential V0)                     # FACT electrostatics (page uses V0/R)
SE_wall = A + R + B  (Schelkunoff slab, plane wave, normal incidence)          # FACT form — Schelkunoff 1943; Ott, EMC Engineering (2009) ch. 6
  γ = sqrt(jωμ(σ + ωε0εr tanδ + jωε0εr)),  η = jωμ/γ
  A = 8.686·Re(γ)·t ;  R = 20log10|(η0+η)²/(4η0η)| ;  B = 20log10|1 − ((η0−η)/(η0+η))² e^(−2γt)|
SE_seam = max(0, 20log10(λ/(2l)) − 10log10 n)   for l < λ/2                # FACT form — Ott (2009) §6.6 slot/aperture
SE_shell = −10log10(10^(−SE_wall/10) + 10^(−SE_seam/10))                      # ASSUMPTION: incoherent sum
RadioScreen shell: 60 dB (<1 GHz), 50 dB (1.3 GHz) page catalog; between INTERPOLATED; above held (ASSUMPTION)
E_leak = E_ref·10^(−SE_shell/20)  (uniform in r)   ·   B_leak = E_leak/c      # ASSUMPTIONS

Interior — EED HYP (future-scalar-ab.html#eed, exactly)

E_r(r) = V0 R [sin kr − kr cos kr] / (r² sin kR),   k = 2πf/c,   E_r(0) = 0
B = 0 (SLW: "radial (longitudinal), zero at the center, and has B = 0");  tangential E = 0
Resonance at kR = π (f = c/2R).  Standard cavity: TM101 ka = 2.744, TE101 ka = 4.493 (FACT)

Exterior — standard

Q = 4πε0 R V0                                                   # FACT isolated-sphere capacitance (counterpoise proximity ignored: ASSUMPTION)
A: E = V0 R / r_c²,  B = 0                                      # FACT electrostatics; valid r_c ≪ λ/2π, far from counterpoise
B: uniform current I0 = ωQ on a line from image centre (−h_c) to sphere centre (+h_c), N = 400 Hertzian elements   # ASSUMPTION
C: single Hertzian dipole I·l = ω(2h_c Q) at the counterpoise                                                    # ASSUMPTION
Hertzian element (Balanis, Antenna Theory 3e, Eq. 4-8a–c, 4-10a):                                               # FACT form
  E_r = η Il cosθ/(2πr²) [1 + 1/(jkr)] e^(−jkr)
  E_θ = jηk Il sinθ/(4πr) [1 + 1/(jkr) − 1/(kr)²] e^(−jkr)
  H_φ = jk Il sinθ/(4πr) [1 + 1/(jkr)] e^(−jkr)
Radiated power (image theory: half-space = ½ full-space): C: ηπ/3 (Il/λ)² (Balanis 4-16); B: uniform line-source integral
Power limit (default ON): if P_rad,model > P_drive, scale B/C fields by sqrt(P_drive/P_rad)   # FACT energy bound; uniform scaling = ASSUMPTION
Probe at sphere-centre height h_c = gap + R, horizontal r_c = R + d

Exterior — HYP (SleeveBalunSNR carry-over)

P_rad = I_pk² Z0/(4π)  (US 9,306,527 Eq. 15) ;  S = P_rad/(4π r_c²)·exp(−αL) ;  E∥ = sqrt(S·Z0)   # HYP / illustrative
B = 0 (SLW) ;  detector power × mP (two tents), as SNR_Hively in sleeve-balun-snr.html

Probe → TinySA → SNR

P_probe = K(f) + 20log10(field/ref) − stack_dB        ref = 1 V/m (E5) or 1 µT (H probes)
K(f): Tekbox TBPS01/TBWA2 manual V2.2 p.2 Pict. 2 (H, dBm at 1 µT), p.3 Pict. 3 (E5, dBm at 1 V/m)
      chart data points extracted from the PDF vector paths; between points linear in log f = INTERPOLATED
      outside the plotted range = NOT PUBLISHED (H20 curve ends at 2000 MHz; others at 3000 MHz)
alt:  Tekbox FAQ V1.1 (2022) p.2: B = 10^((P − S − 20log F_MHz)/20), S = 80/62/40 (H20/H10/H5); E = 10^((P + 112.5 − 20log F_MHz)/20)
Field amplitude: peak amplitude, as the page does (Tekbox does not say rms vs peak)   # ASSUMPTION
floor = −102 dBm + 10log10(RBW/30 kHz)  (no LNA) ;  −145 dBm + 10log10(RBW/200 Hz)  (LNA)   # tinysa.org TinySA4 spec (30 MHz)
SNR = P_probe − floor ;  warnings above −25 dBm (best), −1 dBm (P1dB), +6 dBm (abs max)
