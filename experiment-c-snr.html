Detailed readout

Equations

P_OUT = η_launch · I_peak² Z0/(4π)    (or η_launch · P_RF)
S_geom = P_OUT/(4πr²) ;  S = S_geom exp(−α_ohm L)
P_interact = S A_atom η_atom
photon rate = P_interact/E_gap ; E_gap = 10.2 eV
I_cathode = e · photon_rate · QE · T_optics
I_anode = M · I_cathode + I_dark
ΔI_AM = m · M · I_cathode
V_C9663 = ΔI_AM · Z_transimpedance
P_50Ω = V_rms²/50 ; TinySA tone = 10 log10(P/1mW)

PMT output-current model is a first-order average-current / sinusoidal-envelope picture. Real single-photon work uses pulse height, discriminator, dead time, and count statistics. Keep anode average below the tube’s rated current; never raw anode to TinySA. v1 · 9 Sep 2026.
